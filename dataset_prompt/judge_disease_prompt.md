Two labels were given to one clinical case. Decide whether the two labels name the SAME main disease, at the level of detail we use for the main disease. The labels may name an infection or a non-infectious condition; the same rules apply to both.

Ignore spelling, capitalisation, hyphens, word order, abbreviations and qualifiers that do not change the disease. These are the same wording:
- "bacteraemia" / "bacteremia"; "tuberculosis" / "TB"; "HIV infection" / "HIV-1 infection"
- "maxillary sinus tuberculosis" / "tuberculosis of the maxillary sinus"
- "herpes zoster" / "varicella-zoster virus herpes zoster"
- "herpes zoster radiculomyelitis" / "VZV radiculomyelitis"
- "left lateral medullary infarction" / "lateral medullary infarction"
- "recurrent hepatitis C virus infection" / "hepatitis C genotype 4" (the genotype is detail, the disease is the same)
- "recurrent urinary tract infection" / "recurrent bacterial urinary tract infection" (a class word such as bacterial, viral or fungal names a class, not an organism)
- "herpes zoster neuralgia" / "herpes zoster-associated neuralgia" (associated with and of mean the same link)
- "intraocular foreign body" / "occult nonmetallic intraocular foreign body" (a descriptive word that does not change the disease)

A broad term matches a form, stage or subtype of the same disease. Answer "yes":
- "late congenital syphilis" / "congenital syphilis"
- "post-primary pulmonary tuberculosis" / "tuberculosis"
- "pseudomembranous oral candidiasis" / "oral candidiasis"
- "COVID-19 pneumonia" / "COVID-19" (the same disease, with the organ named)

The organism matters. If one label names the organism of the infection and the other label is generic (no organism), answer "no":
- "infective endocarditis" / "Streptococcus mutans endocarditis"
- "invasive aspergillosis" / "Aspergillus fumigatus tracheobronchial aspergillosis"
- "erythema multiforme" / "VZV-associated erythema multiforme"
- "bacterial meningitis" / "pneumococcal meningitis"

Answer "no" when the labels name different diseases, or one names a complication or manifestation of the other:
- a different disease: "COVID-19" / "pulmonary embolism"; "posterior reversible encephalopathy syndrome" / "dengue fever"
- a complication or manifestation: "herpes zoster" / "herpetic neuralgia"; "dengue encephalitis" / "dengue fever"
- an outcome instead of the disease: "HIV infection" / "HIV-1 virologic failure"
- a different organism: "Pneumococcal meningitis" / "Haemophilus influenzae meningitis"
- a different site: "cerebral toxoplasmosis" / "ocular toxoplasmosis"
- a mixed or co-infection label against a single disease: "dengue and hepatitis A co-infection" / "dengue fever"
